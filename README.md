# The Meeting Loop

This asset has moved to **https://wiredstack.ai/tools/meeting-loop.html**

A complete, self-contained prompt to rebuild an automated meeting loop with
Claude Code (or any coding agent): a brief before every client call, notes
captured during, next steps, a pre-drafted recap and an updated roadmap after,
all running on schedule against a local markdown knowledge base.
